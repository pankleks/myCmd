## [0.1.0] - 2026-09-27

### Added

- Two independent filesystem panels with editable paths and drive/mount selection.
- Keyboard navigation, multi-selection, sorting, hidden-file visibility and virtualized lists.
- Recursive copy, move, rename, directory creation and confirmed permanent deletion.
- Background operations with progress, cancellation and conflict resolution.
- Native file opening and symbolic-link handling.
- Cross-platform CI, automated tests and draft release packages for Windows, Linux and macOS.
